# Project Rules & Non-Negotiable Standards (App Lifestyle 2)

## Core Product Constraints
1. **No Generic Boilerplate:** All strategy and research documents in `docs/` must contain concrete frameworks, behavioral mechanisms, user segments, and evidence-graded interventions—never vague summaries or placeholders (`[TBD]`, `Lorem ipsum`).
2. **Apple-Level Craft:** All prototype components in `prototype/src/` must be polished, interactive, and bug-free.
3. **Strict TypeScript:** All prototype code in `prototype/src/` must pass `npm run build` with zero warnings or errors.

## Workflow Rules
- Work on **ONE** task per session.
- Never mark a task `"completed"` in `tasks.json` until the Reviewer step approves it.
- Keep `PROGRESS.md` updated with concise, factual logs of what was built and verified.
